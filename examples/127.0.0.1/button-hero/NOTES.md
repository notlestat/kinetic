# Taste note

The hero works because almost nothing competes with the button: one line of copy, generous 48 px padding and a white card on a pale page. The CTA earns attention with a saturated violet and a soft 1 px shadow that grows into a 24 px glow on hover, so the lift reads as depth rather than movement. Every transition is short (150 ms, with a slightly slower 200 ms shadow), which keeps the hover feeling immediate. The chip's 4 px rise and the slow pulse on its live dot add life without pulling focus from the primary action.

Could not match: the page's Inter webfont is not available in the sandbox, so text falls back to the system face and wraps slightly differently. The dot's pulse is frame-sampled, so its curve is an ease-in-out approximation.
